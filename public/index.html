App Guide & Troubleshooting

🔒 Are my email credentials safe?

Absolutely. This app runs entirely on your local machine. Your email address and App Password are saved in a local, private database file (database.json) in this directory and are only used to connect directly to your email provider's secure IMAP server.

📧 Gmail Connection setup

For security, Google does not allow apps to login with your normal Gmail password. You must use an App Password:

  1. Go to your Google Account Settings.
  2. Search for or select 2-Step Verification and enable it if not already done.
  3. Scroll to the bottom and select App passwords.
  4. Enter a custom name (e.g. "Job Tracker") and click Create.
  5. Copy the 16-character code and paste it as the password in this app.

🛠️ Other providers host info

  • Outlook/Hotmail: Host: outlook.office365.com, Port: 993
  • Yahoo Mail: Host: imap.mail.yahoo.com, Port: 993 (Requires generating a Yahoo App Password)
  • iCloud Mail: Host: imap.mail.me.com, Port: 993 (Requires an App-Specific Password)

How to Generate Google App Password

Google has disabled "Less secure apps access". To connect this app, you must create a dedicated App Password. It takes 2 minutes:

1
Open Account Settings

Go to your Google Account dashboard.

2
Enable 2-Step Verification

Navigate to Security on the left menu. In the "Signing in to Google" section, make sure 2-Step Verification is turned ON. (If not, follow prompts to set it up).

3
Search for "App Passwords"

At the top of Account settings page, search for "App passwords" in the search box, or scroll to the bottom of the "2-Step Verification" settings to find App passwords.

4
Generate the Password

Type in a recognizable name (e.g. ApplyTrack Email Checker) and click Create.

5
Copy Code

A yellow pop-up box will display a 16-character password (e.g. abcd efgh ijkl mnop). Copy this password (without spaces) and paste it into ApplyTrack Settings!
